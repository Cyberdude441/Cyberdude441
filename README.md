### 🛡️ About Me

I am a **Cybersecurity Researcher and Security Software Engineer** focused on low-level system security, threat intelligence, detection engineering, and security automation. My work bridges offensive exploration and defensive resilience — engineering custom kernel-level eBPF probes, designing SOC detection dashboards, fine-tuning domain-adapted cybersecurity LLMs, and analyzing complex attack vectors.

- 🔬 **Research & Engineering**: Developing runtime threat detection engines (**API Sentinel** with eBPF/Rust) and autonomous security intelligence pipelines (**CyberQwen-AI**).
- 🔍 **Threat Intelligence & DFIR**: Investigating authentication attacks, conducting memory & PCAP log triage, and automating IOC tracking with SOAR-style workflows.
- 🎯 **Offensive Security & CTFs**: Actively auditing attack surfaces (OWASP API Top 10, BOLA, OSINT, DNS recon) and sharpening penetration testing methodologies.
- 💼 **Career Goal**: Seeking Cybersecurity Researcher, SOC Analyst, Detection Engineer, or Security Engineering roles and internships.
